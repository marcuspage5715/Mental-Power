# Solutions for the new rooms

Rooms 37 to 60 are the puzzles that are not in the original game. Below is one
solution for each: every cell of the shape is covered exactly once, and the letters
name the pieces, so you can check any room by hand.

The letters are the pieces: O (the 2x2 square), V, Z, T, F, I, N, W, U, P, X, L, Y.
Every letter is one of the pieces that room actually hands out, so each diagram can be
reproduced with the tray you get in the game. `tools/solutions.py` regenerates this file
and checks that the letters cover every cell exactly once and that each one is a rigid
copy of the piece it names.

Shape 9x6, area 40, pieces: V, T, F, N, W, P, L, Y
